    Everything Astrum does and how to use it, a page per subject. New to it? Start with getting started.

    Getting started

    Your first minutes with Astrum: what is on the screen, a new tab, a split, a question for the agent, and coming back.

    Install

    Install Astrum with one line, check what you download, build it from source, upgrade it, or remove it.

    Using Astrum

    Tabs and panes

    Open, name and move tabs, split them into panes, search and copy the scrollback, follow links, and see the pictures programs print.

    The mouse and the keys

    Every click and menu in Astrum, then the keys: how the prefix key works, how to change the keys, and the full list.

    Sessions that come back

    Shells that keep running when the window closes, sessions that bring their tabs back after a stop or a reboot, and the commands that manage them.

    The login service

    Have the system start a session when you log in and start it again if it stops, with launchd on macOS or a systemd user service on Linux.

    Tabs on other machines

    A tab on a server over your own ssh, whose shells stay there when the connection drops, and taking the agent into a shell you reached yourself.

    The agent

    The agent

    Ask the agent beside your shell. It reads what is there, runs commands in your own shell where you can watch, and asks before it changes things.

    Providers and models

    Connect the agent to Ollama, OpenAI or any compatible endpoint, Anthropic or Amazon Bedrock, keep API keys safe, and choose a model.

    Rules and skills

    Give the agent standing instructions in AGENTS.md files, and skills it loads for particular kinds of work.

    MCP servers

    Give the agent the tools of MCP servers, programs on your machine or services on the network, and choose which it may use without asking.

    Several agents at once

    Each tab has an agent of its own. See what every one is doing, answer one from wherever you are, and be told when one needs you.
